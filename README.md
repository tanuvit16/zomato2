# Zomato Clone (Frontend)

A high-fidelity frontend clone of the Zomato website, built with React and Vite as part of my summer internship project.

## 🛠️ Technologies Used

* **React.js**
* **Vite**
* **HTML5**
* **CSS3** (Flexbox, Grid, Media Queries)

## 📦 Setup and Installation

To run this project locally:

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/tanuvit16/zomato2.git
    ```

2.  **Navigate to the project directory:**
    ```sh
    cd [zomato2
    ```

3.  **Install dependencies:**
    ```sh
    npm install
    ```

4.  **Start the development server:**
    ```sh
    npm run dev
    ```

5.  Open your browser and visit `http://localhost:5173` (or the port specified in your console).
